# 提示词库新增按钮设计

- 日期：2026-07-12
- 状态：设计已确认，等待全部关联规格复核
- 范围：侧边栏“提示词库”的新增按钮视觉与可访问性交互。

## 目标

让新增提示词入口保持容易发现，但不再以渐变、发光与大号文字加号抢占侧边栏注意力。

## 设计

1. 按钮固定为 28 x 28px，保持独立、稳定的点击目标。
2. 使用 Lucide Plus 图标，尺寸 14px；不再渲染文字加号。
3. 常态为透明背景、低饱和青绿色描边与中等对比图标。
4. 悬停与键盘聚焦时使用浅青色背景和更清晰的描边，不改变布局尺寸。
5. 保留 Create prompt 的语义名称，并改用中文 tooltip“新增提示词”。
6. 不改变点击行为：仍打开现有的新建提示词编辑弹窗。

## 验收

1. 按钮不再使用渐变背景或外发光阴影。
2. 正常、悬停与聚焦状态均不导致侧栏布局移动。
3. 鼠标和键盘都能打开现有新建提示词弹窗。
4. 现有创建提示词组件测试继续通过。
