# 香蕉悬浮图标连续动画设计

- 日期：2026-07-12
- 状态：已确认，等待规格复核
- 范围：仅替换悬浮图标的香蕉动画资源与其资源验收，不改变窗口显示、点击、拖动或提醒逻辑。

## 目标

悬浮图标在主窗口收起时，显示一根**尚未剥开**的香蕉。它的角度、粗细、可见尺寸和绘制风格以用户提供的香蕉图为唯一视觉基准；点击后，香蕉皮顺畅打开，不会在第一帧、中间帧或最后一帧产生比例、方向或位置跳变。

## 已确认的视觉决定

1. 使用一组全新的 12 帧透明背景资源，不混用当前旧序列的任何中间帧。
2. 第 0 帧为完整、未剥开的香蕉皮；第 11 帧为完全剥开的香蕉。
3. 第 0 至第 11 帧都采用同一套水平镜像后的方向，保证与浮窗当前打开状态一致。
4. 香蕉主体始终以同一个视觉中心摆放，保持同一角度、粗细和画面占比。只有香蕉皮逐步向外打开，不能突然缩放、旋转或位移。
5. 背景必须完全透明，不加入白色底、阴影底板或额外装饰。
6. 按钮点击区域继续是 `64 x 64px`；只更换其中显示的香蕉图，不改变悬浮窗口的交互面积。

## 帧序列

| 帧 | 状态 |
| --- | --- |
| 0 | 完整香蕉，香蕉皮未打开 |
| 1-3 | 顶端和侧边轻微松开，主体仍是完整香蕉形状 |
| 4-6 | 香蕉皮依次展开到中段；第 6 帧仍是主窗口显示的同步揭示点 |
| 7-10 | 香蕉皮继续向外翻开，主体位置稳定 |
| 11 | 完全剥开的终态，与第 0 帧同角度、同尺度、同视觉中心 |

关闭主窗口时，仍从当前帧反向播放至第 0 帧。动画总时长保持 `360ms`，减少动态效果设置开启时直接切换到目标帧。

## 技术边界

- 最终精灵图路径保持为 `src/assets/banana/banana-peel-sprite.webp`。
- 精灵图固定为 `12 x 256 x 256px` 画布，按水平方向排列，保留透明边缘。
- 第 0 帧与第 11 帧分别同时导出为审核端点：
  - `src/assets/banana/banana-closed-mirrored-approved.png`
  - `src/assets/banana/banana-open-mirrored-approved.png`
- `AnimatedBananaButton.vue` 继续使用同一精灵图播放逻辑；不通过 CSS 旋转、缩放或补偿新资源。

## 验收与测试

1. 第 0 帧的像素与已审核的未剥开端点一致；第 11 帧的像素与已审核的完全剥开端点一致。
2. 12 帧全部具有透明边缘，香蕉不接触 256px 画布边界。
3. 相邻两帧均有可见但有限的像素变化，保证不出现空帧或跳帧。
4. 每帧的可见像素中心与终态中心偏差受限，防止动画在按钮内漂移。
5. 现有 TypeScript 动画单元测试与 Rust 资源完整性测试必须通过。

## 非目标

- 不调整香蕉按钮的 `64px` 点击区域。
- 不修改主窗口、提醒气泡、文件拖放、托盘或快捷键行为。
- 不改变 12 帧、360ms 和第 6 帧揭示主窗口的既有动画协议。
