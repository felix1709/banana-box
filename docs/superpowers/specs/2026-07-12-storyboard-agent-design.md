# 故事板 Agent 与 API 设置设计

- 日期：2026-07-12
- 状态：设计已确认，等待全部关联规格复核
- 范围：故事板 Provider 设置、Agent 对话、会话持久化、Skill 库与流式请求。

## 目标

将当前静态故事板表单替换为可持久化的 Agent 对话工作台。用户在设置页配置故事板模型服务，在故事板页面选择模型、管理会话与 Skill，并获得可复制的 Markdown 分镜提示词。

## 导航

1. 继续复用现有桌面应用的 activeTool 侧栏导航。
2. “故事板”是固定菜单项，点击后显示 Agent 页面。
3. 不引入 vue-router 或 /storyboard URL，避免在现有桌面导航之外维护第二套状态。

## 全局 API 设置

1. 设置的 API 页面提供 Provider 选择器：反推图片与故事板 Agent。
2. 故事板 Provider 独立保存 Base URL、Models URL、Chat URL、API Key、默认模型、温度与上下文长度。
3. API Key 仅经 Rust 后端写入系统凭据；Pinia 只保存可公开的 Provider 数据、模型列表与配置版本。
4. “检测连接”读取 Models URL，刷新模型列表。glm-5.2 在可用时优先作为默认模型。
5. 故事板页面只保留模型下拉框，模型来源是全局已配置模型列表；每个会话保存自己的当前模型选择。
6. 温度与上下文长度仅在设置页面编辑。默认值为温度 0.7、上下文长度 16000；温度允许 0.0 到 2.0，上下文长度允许 512 到 128000。

## 页面布局

1. 页面采用左右两栏。
2. 左栏上半部分是会话列表，支持新建、切换、删除，显示标题与最近更新时间。
3. 左栏下半部分是全局 Skill 库。Skill 可新增，且可为当前会话启用或禁用。
4. 新会话默认启用 storyboard-prompt-optimizer。Skill 库可复用，但启用状态按会话保存。
5. 右栏顶部显示模型下拉、连接状态、清空会话与导出文本图标按钮。
6. 右栏中部是消息流：用户消息右侧深色气泡；Agent 消息左侧浅色气泡。Agent 气泡支持 Markdown、代码块滚动与单条复制。
7. 右栏底部是多行输入、发送图标按钮和当前已启用 Skill 的快捷插入按钮。
8. 内容为空的新会话由 Agent 以选择项开始收集故事、风格、节奏等信息；“其他”显示自定义输入。用户随后可继续自由输入。

## 请求与持久化

1. 发送时，Rust 后端将当前线程消息、当前模型、温度、上下文长度和已启用 Skill 的指定版本组成不可变请求快照。
2. 后端以 OpenAI 兼容 Chat Completions SSE 协议发送 stream: true 请求，前端逐段更新正在生成的 Agent 消息。
3. 每个用户消息、Agent 增量和最终 Markdown 都写入现有 storyboard_threads、storyboard_messages、storyboard_message_blocks 与 agent_requests 表。
4. 打开页面时加载上次使用会话；模型、线程和 Skill 启用状态保持可恢复。
5. 会话内切换模型只影响后续请求；已完成消息和旧请求快照不变。
6. 导出会话和复制单条消息均使用原始 Markdown，不丢失代码块或提示词格式。

## 错误与安全

1. 缺少 API Key、未配置 URL、无模型、网络超时、SSE 中断和服务端错误均在聊天流内显示可读错误气泡。
2. 失败请求保留用户原消息，并提供重试入口；取消或重试不覆盖已经保存的历史。
3. Markdown 禁用原始 HTML、脚本和不安全链接协议。代码块以纯文本渲染，不执行代码。
4. API Key 不进入 Pinia、页面 DOM、日志或会话快照。
5. 单线程同时只允许一个流式请求，防止消息顺序交错。

## 验收与测试

1. 设置页能独立读取、保存并检测故事板 Provider，且不会影响反推图片配置。
2. 对话页从全局 Provider 获取模型列表，默认选择 glm-5.2（可用时），并把会话模型选择持久化。
3. 会话可新建、切换、删除、清空、导出与在重启后恢复。
4. Skill 新增与启用状态按会话保存；每次请求使用对应的 Skill 版本快照。
5. SSE 内容按顺序显示，加载、取消、错误和重试状态可见。
6. 用户与 Agent 气泡有明确位置差异；长 Markdown 和代码块不撑破布局。
7. 复制按钮、导出文本和最终提示词保留原始 Markdown。
8. 针对 Provider、对话仓储、命令、Pinia、页面和 Markdown 安全渲染分别提供自动化测试。
