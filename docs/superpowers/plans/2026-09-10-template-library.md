# 模板词库模块实现计划

- 日期：2026-09-10
- 目标版本：建议 v0.11.0
- 状态：已完成（2026-09-10）

## 目标

在 Banana Box 新增一个“模板词库”模块，内置 `awesome-gpt-image-2` 的 541 个案例与 22 套模板。页面顶部显示 13 个分类，下面是卡片式案例；点开案例看大图和提示词，支持中英文切换、一键复制，并可收藏到现有“提示词库”。

## 页面交互（按用户确认）

1. 顶部横向排列 13 个分类，可左右滚动，点分类过滤案例。
2. 下方卡片网格：每张卡片显示案例图片和标题。
3. 点开卡片弹窗：左边大图，右边提示词。
4. 提示词支持“中文 / 英文”切换，切换只影响提示词正文。
5. 弹窗内两个动作：
   - 复制当前语言的提示词。
   - 收藏到提示词库：把当前案例（标题 + 当前语言提示词 + 图片 + 标签）写入本地提示词库。

## 数据准备（一次性脚本）

1. 从仓库读取 `data/cases.json` 和 `data/style-library.json`。
2. 生成精简数据文件，字段包含：标题、分类、风格、场景、标签、图片路径、英文提示词、中文提示词、来源作者、来源链接。
3. 压缩 544 张案例图片：缩到最长边约 720 像素、转为 WebP 或 JPG，目标总体积 20–30 MB。
4. 生成中文提示词：用 AI 批量翻译 541 条英文提示词，写入 `promptZh` 字段，人工抽查常见分类。
5. 把数据文件和压缩图片打包进 Tauri 资源目录，应用内离线可用。

## 前端改动

1. `src/stores/ui.ts`：`ActiveTool` 增加 `template-library`。
2. `src/components/AppSidebar.vue`：增加“模板词库”入口和图标。
3. 新增 `TemplateLibraryPage.vue`：分类栏 + 卡片网格 + 缩略图懒加载。
4. 新增 `TemplateCaseDialog.vue`：大图、提示词、中英切换、复制、收藏。
5. `src/App.vue`：根据 `activeTool` 渲染新页面。
6. 收藏逻辑：调用 `libraryStore.addPrompt`，自动创建并使用“模板收藏”分类；图片复制到用户图片目录。

## 后端改动

1. 新增 IPC：读取内置模板列表数据。
2. 新增 IPC：读取模板图片和缩略图字节。
3. 新增 IPC：收藏时把模板图片复制到 `images/` 目录，返回相对路径。

## 验证步骤

1. `pnpm check` 全绿。
2. `cargo test --manifest-path src-tauri\Cargo.toml` 全绿。
3. 手工验证：
   - 打开“模板词库”，13 个分类可切换。
   - 点开案例，大图正常、提示词可中英切换、复制成功。
   - 点击收藏后，去“提示词库”的“模板收藏”分类能看到，重启应用后仍在。
   - 图片压缩后安装包体积在可接受范围。

## 已确认决策

- 收藏到提示词库时，默认分类使用“模板收藏”，不额外弹窗选择分类。
- 中英切换默认显示中文，方便浏览；需要英文时可一键切回并复制。
